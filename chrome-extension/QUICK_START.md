# 🚀 دليل البدء السريع - Austria Bot

## 📥 التثبيت (5 دقائق)

### 1️⃣ حمّل Extension

```bash
# 1. تأكد أن عندك المجلد
cd chrome-extension/

# 2. أنشئ الأيقونات (اختر طريقة واحدة):

# الطريقة أ: ImageMagick (إذا متوفر)
cd icons
convert -size 128x128 xc:'#c41e3a' -pointsize 80 -fill white -gravity center -annotate +0+0 'A' icon128.png
convert icon128.png -resize 48x48 icon48.png
convert icon128.png -resize 32x32 icon32.png
convert icon128.png -resize 16x16 icon16.png
cd ..

# الطريقة ب: حمّل من الإنترنت
# اذهب لـ: https://www.favicon-generator.org/
# استخدم emoji 🇦🇹
# حمّل الأيقونات بالأحجام: 16, 32, 48, 128
# ضعها في مجلد icons/
```

### 2️⃣ افتح Chrome Extensions

في Chrome، اكتب في شريط العنوان:
```
chrome://extensions/
```

### 3️⃣ فعّل Developer Mode

- شغّل المفتاح "Developer mode" في الزاوية العلوية اليمنى

### 4️⃣ حمّل Extension

1. اضغط "Load unpacked" (تحميل بدون حزم)
2. اختر مجلد `chrome-extension/`
3. اضغط "Select Folder"

### 5️⃣ ثبّت الأيقونة

- اضغط على أيقونة الدبوس 📌 بجانب Extension
- الأيقونة ستظهر دائماً في شريط الأدوات

## ⚙️ الإعداد (3 دقائق)

### 1️⃣ افتح Extension

اضغط على أيقونة Austria Bot في الشريط

### 2️⃣ املأ الإعدادات

**تبويب "الإعدادات":**
- المنظمة: `KAIRO` (أو مدينتك)
- نوع الحجز: `Bachelor` (أو نوع تأشيرتك)
- إعادة البحث: `30` ثانية
- تأخير التنقل: `800` ms
- الموعد المفضل: `أي موعد متاح`
- صوت التنبيه: `alert` (الأقوى)

### 3️⃣ املأ البيانات الشخصية

**تبويب "البيانات الشخصية":**
- الاسم الأول: مثلاً `Ahmed`
- اسم العائلة: مثلاً `Mohamed`
- تاريخ الميلاد: بصيغة `01.01.1990`
- رقم الجواز: مثلاً `A12345678`
- باقي الحقول...

**⚠️ مهم جداً:**
- تأكد من صحة **جميع البيانات**
- التواريخ بصيغة `DD.MM.YYYY`
- كل الحقول مطلوبة

### 4️⃣ احفظ

اضغط "💾 حفظ الإعدادات"

## 🐛 مشاكل شائعة

### البوت لا يعمل؟

```
✅ حفظت الإعدادات؟
✅ فعّلت البوت (مفعّل 🟢)؟
✅ أنت على موقع السفارة؟
```

**جرب:**
1. افتح Extension
2. إيقاف → تشغيل
3. أعد تحميل الصفحة (F5)

### لا تظهر رسائل في Console؟

1. اضغط F12
2. اذهب لـ Console
3. ابحث عن `[AustriaBot]`

إذا لا توجد → أعد تحميل Extension:
1. اذهب لـ `chrome://extensions/`
2. اضغط "Reload" على Austria Bot

### التنبيه لا يعمل؟

- تأكد الصوت غير مكتوم
- غيّر صوت التنبيه من الإعدادات
- جرب `alert` - الأقوى

## 💡 نصائح ذهبية

### 🥇 للحصول على موعد أسرع:

1. **قلل زمن إعادة البحث** → `15-20` ثانية
2. **اختر "أي موعد متاح"** → لا تحدد موعد معين
3. **شغّل في هذه الأوقات:**
   - 🌅 الصباح الباكر: 6-8 صباحاً
   - 🌙 منتصف الليل: 12-2 صباحاً
   - المواعيد الملغاة تظهر غالباً في هذه الأوقات

4. **اترك التبويب مفتوح** → لا تغلق التبويب
5. **ارفع صوت الجهاز** → لتسمع التنبيه
6. **جهّز بياناتك** → تأكد من صحة كل شيء

- ✅ لا يتم إرسال أي شيء لأي سيرفر
- ✅ الكود مفتوح المصدر

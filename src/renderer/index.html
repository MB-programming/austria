Orbtasoft — Automation Software

Version 1.0  |  Effective Date: 2025

1. Purpose

Orbtasoft is a desktop automation tool designed exclusively to assist users in submitting appointment booking requests through publicly accessible web forms. It operates by automating repetitive user actions such as form navigation, field population, and submission — tasks that any user could perform manually in a standard web browser.

2. Authorized Use Only

This software is intended solely for lawful personal use. You may only use Orbtasoft to submit genuine appointment requests on your own behalf or on behalf of individuals who have explicitly authorized you to do so.

This software is a pure automation assistant. It does not store or transmit your personal data to any external server. All data entered remains on your local machine.

# Austria Appointment Bot

برنامج سطح مكتب لأتمتة حجز المواعيد في موقع appointment.bmeia.gv.at

## المميزات
- ملء الفورم تلقائيًا ببيانات الشخص
- اختيار أول موعد متاح
- حل الكابتشا تلقائيًا باستخدام GPT-4o
- التنقل التلقائي بين خطوات الحجز
- واجهة عربية سهلة الاستخدام
- يعمل على Mac و Windows

## التثبيت والتشغيل

```bash
npm install
npm start
```

## البناء (Build)

```bash
# Mac
npm run build:mac

# Windows
npm run build:win

# الاثنين
npm run build:all
```

## الإعداد

1. افتح تبويب **الإعدادات** وأضف OpenAI API Key
2. افتح تبويب **بيانات الشخص** وأدخل بيانات الشخص
3. اضغط **تشغيل البوت** من تبويب التشغيل

## المتطلبات
- Node.js 18+
- مفتاح OpenAI API (لحل الكابتشا)
